# NordicShop AKS Platform

A learning-led portfolio project for building and operating a small multi-tenant marketplace on Azure Kubernetes Service.

The repository structure is prepared up front from the project plan. Future-phase folders are placeholders only until those phases are built, tested, and understood.

## Planned platform

- Customer Web
- Vendor Portal
- Admin Portal
- Nordic API
- PostgreSQL
- Redis
- Terraform-provisioned Azure foundation
- AKS and ACR
- Helm
- GitHub OIDC
- Argo CD
- Workload Identity and Key Vault
- Observability, security testing, controlled recovery, cost and teardown evidence

Current stage: repository baseline and application orientation.
